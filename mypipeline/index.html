7-stage pipeline placement

How your pipeline and MCP fit together

1. Fetch
fetcher.py builds raw source inventory.
2. Parse
parser.py normalizes OpenAPI, Swagger, HTML, and Markdown.
3. Enrich
enricher.py adds categories, auth placeholders, and notes.
4. Publish
publisher.py writes marketplace/index.json and apis/*.json.
5. Validate
validator.py removes malformed or unsafe templates.
6. Deploy
deployer.py prepares GitHub Pages structure.
7. Search
search_indexer.py supports fast browsing. MCP now sits here.
MCP tool bridge

Inline tool output
